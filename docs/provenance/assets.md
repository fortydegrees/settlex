# Asset identities

[assets.tsv](assets.tsv) records the 409 tracked paths under `public/`, `sounds/`
and `design/` at snapshot `1c9d7000b0da4d7cae3e6c4837319c7784267bed`.
It includes file modes, Git blob IDs and logical sizes, including supporting
source and readme files. It is a historical identity table.

[archived-assets.tsv](archived-assets.tsv) identifies the 244 omitted reference
and optional files for private recovery. Where the tables differ, that newer
archive entry identifies the omitted version. See [current assets](asset-disposition.md)
for runtime scope and compatibility.

David Pratt's 60 original Inkscape board-piece files are marked
`original-artwork-david-pratt-inkscape`. Other rows retain their recorded status.
See [artwork and fonts](art-and-fonts.md), [sounds](sounds.md) and
[third-party notices](../../THIRD_PARTY_NOTICES.md) for the corresponding records.
File identity alone does not establish license terms.
