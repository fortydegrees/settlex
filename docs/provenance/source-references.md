# Source references

## Adapted board specification

`game-core/src/spec.ts` adapts the standard-board specification from
[settlers-setup](https://github.com/cgagliardi/settlers-setup/blob/5ae568ae5cbaf5a35a25f20bfd54a6c38d4c5b0a/src/app/board/specs/standard.ts),
including resource-count construction, board-spec fields and roll numbers.
Local geometry, ports and bank setup differ. Copyright (c) 2020 Cory Gagliardi;
the complete [MIT notice](../../LICENSES/settlers-setup-MIT.txt) remains bundled.

## Documentation references

[Red Blob Games](https://www.redblobgames.com/grids/hexagons/) explains the
standard hex-coordinate math used by the board.
[boardgame.io phases](https://boardgame.io/documentation/#/phases) documents the
framework's turn and phase lifecycle. These are explanatory references.
