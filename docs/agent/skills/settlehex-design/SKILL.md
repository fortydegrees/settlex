# SettleHex brand guide — superseded

The former colour, typography, shadow, button and modal class recipes were
superseded by Clarity and later user decisions. They are removed from this
entrypoint so old links cannot silently reintroduce them; Git retains history.

Use these maintained sources:

- `docs/agent/UI_CONTEXT.md`: task and surface routing.
- `docs/agent/DESIGN_SYSTEM.md`: product intent, foundation ownership and
  interaction responsibilities.
- `docs/agent/UI_CATALOG.md` and production Storybook: component owners,
  supported states and existing implementations, not blanket design sign-off.
- `docs/agent/PROJECT_RECORD.md`: current decisions and provenance; check dated context.

Specialist references in this directory remain active for their named tasks:
`SOUND_DESIGN_GUIDE.md`, `RESOURCE_ICON_STYLE_GUIDE.md`,
`DESIGN_REVIEW_CHECKLIST.md`, and `ADDING_SHARED_PRIMITIVES.md`.
