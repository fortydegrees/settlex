# SettleHex brand exploration handoff

This folder is a self-contained brief for a fresh Claude Opus brand exploration.
It is intentionally separate from production code and does not approve a logo
change.

## How to use it

1. Start a fresh Claude Opus conversation or project.
2. Attach `CLAUDE_OPUS_PROMPT.md`, `BRAND_CONTEXT.md`, and the seven images in
   `attachments/`.
3. Paste the full contents of `CLAUDE_OPUS_PROMPT.md` as the request.
4. If Claude has repository access, also point it at the optional source files
   listed in the prompt.

The requested output is a critical visual exploration and recommendation, not a
production implementation.
